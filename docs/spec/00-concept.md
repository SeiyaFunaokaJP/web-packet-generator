# 00. コンセプト / ゴール

Status: draft / 元: TODO.md §0

## 目的

NW 機器・NW 構成の検証用に、任意のパケットを GUI で組み立て、超高速に送出できるツール。

## 対象ユーザー

| ユーザー | 主な利用シーン |
|---|---|
| NW エンジニア | 機器の動作確認、設定変更後の疎通・負荷確認 |
| 検証担当 | 再現性のある試験シナリオ (テンプレート) の作成と共有 |
| CML2 / EVE-NG 等のラボ利用者 | 仮想ラボ内ノードに単一バイナリを投入して送出 |
| プロトコル実装者 | 独自実装への異常系・境界値パケットの投入 |

## 差別化

1. IS-IS / CLNP など OSI 系まで含む「深い」プロトコル対応
2. DPDK / AF_XDP まで使う高速送出
3. GUI + テンプレート共有による「誰でも再現できる検証」

## 基本方針

- 言語: Rust 一択 (バックエンド、パケットエンジン、フロントエンド WASM まで)
- 配布: 単一バイナリ (フロントエンド資産を埋め込み) + スクリプト群。Windows / macOS / Linux
- 多言語: 日本語・英語 (UI / マニュアル / エラーメッセージ)。追加可能な構造

## 非ゴール (v1)

- フル機能のパケットキャプチャ/解析。Wireshark の代替にはならない。受信は検証カウンタ・簡易表示まで。
- ステートフルなセッション生成 (TCP 3-way handshake 完走、HTTP クライアント等)。v2 以降で検討。
- 攻撃ツール用途への最適化。検証用途に限定し、利用者責任をドキュメントで明記する。
