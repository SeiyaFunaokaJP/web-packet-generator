# 06. GUI (wpg-web)

Status: draft / 仕様 §2.5 / 技術: Leptos (CSR) + Tailwind ([ADR-0002](../adr/0002-frontend.md))

## 画面構成

1. **ダッシュボード**: 実行中ジョブ、インタフェース状態、直近の統計グラフ
2. **ビルダー**
   - 左: プロトコルパレット (検索 / カテゴリ / お気に入り)
   - 中央: レイヤスタック (D&D で追加・並替・削除)
   - 右: フィールドエディタ (型別入力 UI、Auto/Manual、ジェネレータ設定)
   - 下: Hex ダンプ + ツリー (双方向ハイライト、クリックでフィールドへジャンプ、Hex 直接編集で逆反映)
3. **ストリーム/ジョブ**: 複数テンプレ混合、レート・回数・インタフェース設定、ドライラン (pcap 出力)、開始/停止/一時停止
4. **テンプレート**: 一覧・検索・タグ・インポート/エクスポート・共有
5. **受信/検証**: カウンタ・簡易表示
6. **設定**: 言語、テーマ (ライト/ダーク)、認証、バックエンド設定、ライブラリパス

## 操作性

- 全操作にキーボードショートカット、Undo/Redo、自動保存 (ローカル draft)
- 人間向け表記の入力 (`192.168.1.1-192.168.5.254`, `00:11:22:*`, `49.0001.1921.6800.1001.00`)。パースエラーは即時表示。
- プレビューはブラウザ内 WASM で即時合成。サーバ側合成結果との一致を同一 crate で保証する。
- レイヤ追加時の「次ヘッダ自動設定」と、逆に「上位レイヤに合わせて下位を提案」
- モバイル/狭幅は閲覧のみ (編集はデスクトップ想定)

## i18n

全文字列を Fluent 化。ブラウザ言語自動判定 + 手動切替。プロトコル名・フィールド説明も多言語。

## アクセシビリティ

aria 対応、コントラスト、キーボードのみで D&D 相当の操作が可能であること。

## 性能

9000B のジャンボフレームでも滑らかに動くよう、Hex ダンプは仮想スクロール (canvas フォールバックを検討)。→ [11-risks.md](11-risks.md)

## 未決事項 (Open questions)

- Hex 直接編集の逆反映で、Auto フィールドを Manual に変える規則。
- Undo/Redo の粒度と、自動保存 draft の保存先 (localStorage / サーバ)。
- 統計グラフのライブラリ (自作 canvas か既存 crate か)。
- E2E (Playwright) の対象ブラウザ範囲と最小サポートブラウザ (現状の `e2e/` は Chromium のみ)。
