# Protocol reference

Status: draft

This chapter will be generated automatically from the protocol definition IR, so it always matches the code. Each protocol page will list its fields, types, auto-calculated values and constraints. Protocols are grouped by priority from P0 (MVP) to P3 (user-defined). Generation is planned for milestone M11.

Stacking, Auto fields, approximations and their workarounds, which generated tables cannot convey, are collected in the [P1 protocol notes](p1/README.md).
