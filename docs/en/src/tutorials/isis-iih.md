# Tutorial: IS-IS IIH

Status: draft

This tutorial builds an IS-IS LAN Hello (L1/L2 IIH) over 802.2 LLC with DSAP/SSAP 0xFE. You will fill in the Area Address, Protocols Supported and IP Interface Address TLVs and let wpg calculate the PDU length and padding. It is intended for testing adjacency behavior on a router in a CML2 lab. Point-to-point IIH is covered as a variation.
