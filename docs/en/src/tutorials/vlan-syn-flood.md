# Tutorial: VLAN-tagged TCP SYN flood

Status: draft

This tutorial generates TCP SYN packets inside an 802.1Q VLAN with randomized source ports and addresses. It shows how to set the rate in pps or as a percentage of line rate and how to pick a backend. Because this is high-volume traffic, run it only against equipment you own or are authorized to test. The send-limit policy is demonstrated as a safeguard.
